04. Attention：大模型的“阅读重点”机制

Attention 让每个 token 在生成表示时，按权重查看前面的 token，从而把上下文关系带进当前表示。

AttentionQKVCausal Mask
从场景开始 直接看演示

Scenario

为什么需要这一讲

一句话里每个词的重要性不同。模型生成最后一个词时，不能平均看前面所有词，而要知道当前最该关注谁。

Mental Model

先建立一个直觉

Attention 像读文章时划重点：当前词带着一个问题去前文找线索，相关的地方权重大，不相关的地方权重小。

取出 Attention 矩阵

这段代码把模型内部的注意力权重取出来，并标出每个 token 最关注谁。

  24 def visualize_attention(text, layer=0, head=0):
  25     """可视化指定层、指定头的 Attention 分数矩阵"""
  26     input_ids = tokenizer.encode(text, return_tensors="pt")
  27     tokens = [tokenizer.decode([id]) for id in input_ids[0]]
  28
  29     with torch.no_grad():
  30         outputs = model(input_ids)
  31
  32     attention = outputs.attentions[layer][0, head].numpy()
  33
  34     print(f"\n输入: '{text}'")
  35     print(f"Tokens: {tokens}")
  36     print(f"Layer {layer}, Head {head} 的 Attention 矩阵：")
  37     print()
  38
  39     max_tok_len = max(len(t) for t in tokens)
  40     col_w = max(max_tok_len + 1, 7)
  41
  42     # 表头
  43     header = " " * (max_tok_len + 3)
  44     for t in tokens:
  45         header += f"{t:>{col_w}}"
  46     print(header)
  47     print(" " * (max_tok_len + 3) + "-" * (len(tokens) * col_w))
  48
  49     for i, token in enumerate(tokens):
  50         row = f"{token:>{max_tok_len}} │"
  51         for j in range(len(tokens)):
  52             if j > i:
  53                 row += f"{'·':>{col_w}}"
  54             else:
  55                 score = attention[i][j]
  56                 row += f"{score:>{col_w}.3f}"
  57
  58         # 最关注谁（只看因果掩码范围内）
  59         max_j = attention[i][:i + 1].argmax()
  60         row += f"  ← 最关注 '{tokens[max_j]}'"
  61         print(row)
  62
  63     return attention, tokens

  66 def attention_heatmap_ascii(attention, tokens, title=""):
  67     """用 ASCII 字符画出 Attention 热力图"""
  68     blocks = " ░▒▓█"
  69
  70     if title:
  71         print(f"\n{title}")
  72
  73     max_tok_len = max(len(t) for t in tokens)
  74
  75     print(" " * (max_tok_len + 3), end="")
  76     for t in tokens:
  77         print(f"{t[:4]:>5}", end="")
  78     print("  ← Key")

  80
  81     for i in range(len(tokens)):
  82         print(f"{tokens[i]:>{max_tok_len}} │ ", end="")
  83         for j in range(len(tokens)):
  84             if j > i:
  85                 print("   · ", end="")
  86             else:
  87                 score = attention[i][j]

python3 llm/04-attention/attention.py "The capital of France is" --layer 0
python3 llm/04-attention/multi_head.py "The capital of France is" --layer 11
  • Attention 矩阵会显示每个 token 对前面 token 的关注权重。
  • 右上角未来位置不可见，这是因果掩码的效果。
  • 不同层、不同头可能关注不同 token，说明模型在多角度读取上下文。
  • 最后一个 token 的注意力变化，可以直观看到模型如何汇总前文。

Takeaway

这一讲看懂什么

  • Attention 负责在上下文里分配注意力权重。
  • 因果语言模型只能看当前位置及之前的 token。
  • 多头注意力让模型能同时从多个角度理解一句话。

Key Points

讲解要点

  • Q、K、V 可以理解为：我在找什么、每个词提供什么索引、真正取走什么信息。
  • Attention 不是人类意义上的专注，而是一组可计算的权重。
  • 因果掩码保证模型不能偷看未来答案。

Pitfalls

容易误解

  • Attention 权重不是完整解释，只是一个重要观察窗口。
  • 某个 head 看起来奇怪很正常，多头合起来才构成整体效果。
  • 上下文越长，Attention 的计算成本越高。
