- Explain the original article, not every source line. No live model run is claimed.
- 42 is the article's illustrative value, marked as such in voice and picture.
- Distinguish text-only mode from product categories; chat products can use tools.
- No tool call is this minimal loop's stopping condition, not proof of success.
- Iteration cap is not a permission system. No claim all agents share this exact architecture.
- All production roles use the current conversation model; no independent director is available.
- Pilot is unapproved until viewed by the user.
